# Bilingual ATM (C#)

A console ATM simulator written in C# with English and Persian (فارسی) support.

## Features
- Language selection (English / فارسی)
- PIN login with 3 attempts
- Check balance, withdraw, deposit, and transfer
- Input validation (no crashes on wrong input, no negative amounts)

## How to run
1. Install the [.NET SDK](https://dotnet.microsoft.com/download)
2. Create a console project with `dotnet new console`
3. Replace `Program.cs` with the file from this repository
4. Run `dotnet run`
